7. Arrows Redux

arrows-redux

A faithful, cleanly-redrawn version of the shipped concept — the two-arrows-in-a-loop with a code element inside — not a new idea. Fixes what made the original read as jumbled: the two arcs previously swept ~290° each and nearly doubled up into one solid ring with no visible gaps; here each arc is a clean ~120° sweep with a real 60°-wide gap on both sides, at a heavier stroke weight, and the center glyph is redrawn as two bold filled geometric chevrons (a real < > shape at icon weight) instead of an 11px rendered font string that vanished at favicon size.
